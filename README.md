# Subject-Wise Attendance Tracker

A clean, web-based attendance tracking system designed to help students easily monitor their daily subject-wise attendance and maintain their required percentages. 

## 🔗 Links
*   **Live Demo:** [View Live Site](https://soumadip25.github.io/Attendance-ssystem/)
*   **Repository:** [GitHub Repo](https://github.com/soumadip25/Attendance-ssystem)

## ✨ Features
*   **Subject-Specific Tracking:** Log and monitor attendance for individual courses separately.
*   **Dynamic Calculations:** Automatically calculates the current attendance percentage based on classes attended versus total classes conducted.
*   **Intuitive UI:** Clean and responsive interface designed for quick, daily updates.

## 🛠️ Tech Stack
*   HTML
*   React
